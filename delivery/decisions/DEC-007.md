# DEC-007: Validate recovery production and deployment costs

## Context and verified evidence

The accepted sustainability model establishes that current recovery is nonviable under existing work limits, but does not provide energy, physical-network, labor or monetary costs. The owner selected “Validate production cost” rather than keeping caps, limiting to prototype or changing the trust model.

## Decision

Authorize a bounded cost-validation pass for the existing RSO5 diagnostic. Measure locally available elapsed time, CPU, peak memory and disk activity without imposing a work ceiling. Define the independent network, power, failure/repair and operator-labor evidence required for a later economic decision.

## Boundaries

- Preserve source, thresholds, trust, physical safety and existing evidence; no work optimization, implementation, campaign, production routing, deployment, Git/CI or release action.
- Local measurement is diagnostic and does not qualify K1/K2/K3/K7/K8 or production economics.
- Do not infer joules from work bytes, physical network from in-process transport, or independent operator cost from local tests.
- Independent deployments, physical power measurement, new external traffic and pilot operations require separate owner authorization and sanitized evidence.
- Do not run concurrent builds/tests during the local resource measurement; record host/runtime and any isolation limitations.
