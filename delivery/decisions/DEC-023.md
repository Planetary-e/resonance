# DEC-023: Production qualification path for client-held discovery

## Context

The owner requested production qualification for the DEC-022 in-process prototype. The independent code review accepted only a bounded in-process implementation. Live relay/client integration, external networks, process-death and physical/deployment evidence are still missing; K5/K6, FEAT-001 and all K1–K8 remain open.

## Decision

Authorize the production-qualification work path:

1. Live relay server RPC and network-client integration using the reviewed stores and strict protocol bindings.
2. Real loopback and packet-impaired network tests, cold/warm connections, process death and recovery at durable barriers.
3. Complete local resource measurement and maximum-cardinality/fault matrices without weakening existing deadlines or quotas.
4. Independent qualification review and a precise list of unresolved production gates.
5. Only after local qualification, seek the separate operational approvals needed for independently operated deployment and the K8 pilot.

## Boundaries

- Preserve every DEC-021/022 safety, privacy, exact-retry, authorization and resource control. No test weakening, deadline extension, quota escape or uncharged work.
- No production/deployment/release claim from local evidence. No external deployment, installer, model arm or stopped-campaign rerun is authorized by this decision.
- Existing K5/K6 and FEAT-001 failures/open gates are not waived. Qualification must report them rather than claiming a subset is production acceptance.
- Use fixed derivation/embedding fixtures unless a separate model decision is made.
- Commit and push coherent validated work. Independent code/protocol review is required before any production decision.
