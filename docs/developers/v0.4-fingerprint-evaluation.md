# Real-text fingerprint screening

Run from the repository root with the existing local FP32 model cache:

```sh
npm run eval:scoped-fingerprint:real -- --enforce --out /tmp/resonance-fingerprints.json
```

The command refuses model downloads and existing output files. It hashes the
four model artifacts and labeled dataset, uses the production complementary
embedding path, and emits JSON plus Markdown. `--enforce` returns a nonzero
status when a predetermined gate fails; omitting it records negative results
without making the command fail. This opt-in measurement does not download a
large model on every CI run or build an installer.

The [recorded run](../evals/scoped-fingerprint-real-2026-10-18.md) preserves
relative recall within five percentage points. That is not sufficient absolute
quality: 48 of 50 labeled negative pairs clear the static pilot's 0.65 candidate
threshold. Retrieval at five finds 48 of 50 labeled targets in the 100-offer
corpus. These measure candidates before any later encrypted confirmation, not
confirmed matches or real-network precision. A separate holdout corpus is needed
before changing thresholds; do not tune and certify on this same fixture.

Public group/month matrices eliminate identical hashes across scopes, but that
does not establish unlinkability. A fingerprint-only attack estimates an
embedding direction from each public matrix and its hash, then compares the
estimates. It links 86–97% of this fixed 100-offer population, versus 1% random
top-one selection. An adversary knowing these exact candidate texts identifies
them uniquely in both scopes in every case. The 5% screening target fails.
Neither experiment estimates an arbitrary-world text-recovery probability.

Decision: do not activate the public-matrix rotation prototype or claim it
protects against colluding observers. Keep its failed gate visible. A revised
construction must separately address searchable similarity leakage and known
content, and be evaluated before migration changes live publication epochs.
The existing static pilot remains experimental and still exposes these risks.
This decision does not complete the live-rotation roadmap item.

The result is consistent with the broader warning in Turati et al.,
[Locality-Sensitive Hashing Does Not Guarantee Privacy](https://arxiv.org/abs/2302.13635),
which demonstrates attacks on FLoC and MinHash-based systems. Their systems and
attacks differ from this experiment; our measured rates come from the retained
Resonance run, not from that paper.

Resource observations cover this one local process and model initialization,
not full-app memory, Internet traffic or device energy. Corpus size, same-record
population, English language and exact known-text assumptions limit the result.
