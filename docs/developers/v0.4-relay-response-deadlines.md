# Relay response arrival deadlines

## Finding

Signed response timestamps prove when the peer says it answered. They do not
prove that the answer arrived while the local caller still had time remaining.
Several replica response handlers relied only on a timer callback; query and
mailbox handlers also accepted an arrival exactly at expiry. A busy event loop
or changed wall clock could therefore let an authentic late reply resolve work
before the delayed timeout callback ran.

The baseline regression group reproduced eleven such failures. Signature and
request-binding controls already passed; this was a live deadline defect.

## Change

Every covered pending request snapshots its original wall interval and monotonic
deadline before sending. Acceptance requires `createdAt <= now < expiresAt` and
a monotonic time strictly before the smaller of the original local timeout and
signed lifetime. Reverse requests also account for time already elapsed before
intake. Neither a delayed timer nor a wall-clock rollback can extend that budget.

The guard follows existing signature, request, peer and applicable socket checks.
An authentic bound late reply rejects the pending operation without closing a
healthy shared connection. Already-expired requests ignore later signed replies.
Malformed or misbound replies keep their existing refusal behavior. A late receipt
can no longer be treated as current placement/presence evidence through these paths.

Covered handlers:

- Outbound relay link: search replies, publication mailbox sync, relationship
  mailbox sync, replica placement receipts, single/batch inventory and reconciliation.
- Reverse replica link: its shared request path covers placement, batch inventory,
  reconciliation and both mailbox families.
- Relay server: queries over inbound volunteer links and shutdown handoff replies.

The wire formats, timers, quorum and resource caps are unchanged. This closes a
specific arrival-boundary finding, not the entire protocol audit.

## Verification

The final focused/compatibility group passes **66 tests across seven files**.
It covers authentic wrong-key/request/peer/socket responses, exact and later wall
expiry, frozen wall clocks with expired monotonic budgets, both orderings of local
and signed lifetime, inbound server query/handoff controls, reverse presence,
ordinary routing/placement, and continued shared-link use after a late reply.
Independent review approved the guard and its call sites. Composed TypeScript
and strict standalone evaluator typechecking also pass.
